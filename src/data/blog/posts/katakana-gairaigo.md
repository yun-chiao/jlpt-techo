## 片假名為什麼特別難記？（快速答案）

**因為閱讀量天生不足：平假名在每個句子都出現，片假名只在外來語出現，接觸頻率可能不到十分之一，所以「學過但不熟」。解法不是重新背五十音，而是刻意增加閱讀量——每天讀菜單、商品名、遊戲角色名等片假名密集的素材，兩週就能明顯改善。** 字形混淆（シ/ツ、ソ/ン）則靠「筆勢方向」一個原則就能終結。

## シ・ツ・ソ・ン怎麼分？一個原則搞定

四大魔王的分辨關鍵是**筆畫的方向**：

| 字 | 唸法 | 筆勢 | 記法 |
|---|---|---|---|
| シ | shi | 點是橫的，長筆由下往上挑 | 跟平假名し一樣「由下往上」 |
| ツ | tsu | 點是直的，長筆由上往下撇 | 跟平假名つ一樣「由上往下」 |
| ソ | so | 一點，長筆由上往下 | 想成そ的最後一筆方向 |
| ン | n | 一點，長筆由下往上 | 想成ん的收筆方向 |

口訣：**「シ、ン往上挑；ツ、ソ往下撇」，而且每個片假名的筆勢都跟對應的平假名同源**——知道這點之後就不用死背了。

## 英文轉片假名有規則嗎？有，而且很固定

掌握轉換規則，看到新外來語就能自己拼出來：

| 規則 | 英文 | 片假名 |
|---|---|---|
| 子音結尾補母音 u | bus | バス |
| t/d 結尾補 o | test | テスト |
| 長母音用「ー」 | car | カー |
| L 和 R 不分，都用ラ行 | light / right | ライト |
| th → サ行 | think → シンク | サンキュー（thank you） |
| V → バ行（或ヴ） | video | ビデオ |
| 重音節常變促音ッ | cup | カップ |

例：你第一次看到「フライドポテト」，按規則反推 fried potato，秒懂是薯條。**片假名不是新單字，是加密過的英文**——解密規則熟了，字彙量直接繼承你的英文。

## 小心！和製英語：英文母語者也聽不懂的「英文」

這些字長得像英文，意思卻是日本自創的，考試和日常都是陷阱：

| 和製英語 | 真正意思 | 正確英文 |
|---|---|---|
| サラリーマン | 上班族 | office worker |
| アルバイト | 打工 | part-time job（源自德語 Arbeit） |
| マンション | （高級）公寓 | apartment / condo |
| コンセント | 插座 | outlet / socket |
| ホッチキス | 釘書機 | stapler |
| バイキング | 吃到飽 | buffet |
| クレーム | 客訴 | complaint |
| カンニング | 作弊 | cheating |
| パン | 麵包 | bread（源自葡萄牙語 pão） |

> クレーム（claim→客訴）和カンニング（cunning→作弊）是 N3～N2 語彙題的常客——出題者最愛考「你以為的英文意思」和「日文實際意思」的落差。

## 把片假名練熟的三個實戰方法

1. **菜單特訓**：日本連鎖店官網菜單（麥當勞、星巴克、薩莉亞）是片假名密度最高的天然教材，全部唸出聲並猜原文
2. **遊戲・動漫角色名**：寶可夢名字（ピカチュウ、リザードン）是無痛練習素材，你的既有知識會自動校對讀音
3. **手寫易混組**：シツソン、ク/ワ/フ、コ/ユ/ヨ 這幾組每天各寫五遍，寫的時候唸出聲——手部記憶比純視覺辨認牢固得多

## 常見問題 FAQ

**Q：片假名單字在 JLPT 占多少？**
A：不少。N5～N4 每回必考數題片假名語彙，N3 以上外來語比重更高（尤其職場相關：スケジュール、プレゼン、キャンセル）。生活中日文的外來語比例也持續上升，躲不掉的。

**Q：為什麼有些字有兩種寫法，像バイオリン和ヴァイオリン？**
A：ヴ是為了更貼近原音 V 而生的表記，正式度較高但日常較少用。JLPT 以常見表記為主，兩種都認得即可。

**Q：促音ッ和長音ー聽不出來怎麼辦？**
A：靠最小對比組專練：カット（cut）vs カード（card）、バック（back）vs バーグ（burg）。長短音是中文母語者的通病，用[聽解訓練法](/blog/jlpt-listening)裡的跟讀練習最有效。

**Q：外來語的重音跟英文一樣嗎？**
A：不一樣，日文化之後重音會重新分配（英 COFF-ee → 日 コーヒー是平板偏尾高）。別用英文重音唸片假名，那是「日文單字」不是英文。
